# Pansofie Art Kit v1

Independent transparent illustrations for the React UI.

Principles:
- no text baked into artwork
- no screenshot crops
- no card/background baked into artwork
- HTML owns copy, controls and language
- artwork is decorative and can move independently at responsive breakpoints
