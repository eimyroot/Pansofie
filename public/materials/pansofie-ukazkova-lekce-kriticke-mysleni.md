# Pansofie — ukázková lekce: Ověř, co je pravda

**Typ:** krátká zkušenost pro školní skupinu  
**Doporučený čas:** 45–60 minut  
**Téma:** kritické myšlení, práce se zdroji, nejistota a důkaz  
**Princip:** problém → ověření → důkaz → reflexe

## Cíl

Účastníci si vyzkouší rozdíl mezi tvrzením, názorem, zdrojem a důkazem. Nejde o test osobnosti ani o bodování člověka. Hodnotí se pouze kvalita postupu a to, co je možné doložit.

## Zadání

Vyberte jedno konkrétní tvrzení, které se šíří online nebo ve vašem okolí. Může se týkat technologie, přírody, školy, zdravého životního stylu nebo jiné běžné oblasti, která nevyžaduje odborné klinické či právní rozhodování.

Příklad: „Používání telefonu před spaním vždy zhorší spánek.“

## 1. Co přesně tvrzení říká?

Přepište tvrzení vlastními slovy tak, aby bylo jasné, co by muselo být pravda, aby tvrzení platilo.

- Co je tvrzení?
- Co je pouze interpretace?
- Obsahuje slova jako „vždy“, „nikdy“, „všichni“ nebo „určitě“?

## 2. Jaké zdroje máme?

Najděte alespoň tři různé zdroje. U každého zaznamenejte:

- autora nebo instituci,
- datum,
- kde zdroj vznikl,
- jaký důkaz skutečně obsahuje,
- co z něj naopak zjistit nelze.

## 3. Co si zdroje odporují?

Vytvořte jednoduchou tabulku:

| Zdroj | Co podporuje | Co zpochybňuje | Co nevíme |
|---|---|---|---|
| A |  |  |  |
| B |  |  |  |
| C |  |  |  |

## 4. Rozhodnutí

Zvolte jeden z výroků:

- **DOBŘE DOLOŽENO** — pro tvrzení máme dostatečně silné a relevantní důkazy.
- **ČÁSTEČNĚ DOLOŽENO** — část tvrzení má oporu, část je příliš široká nebo nejistá.
- **NEDOSTATEK DŮKAZŮ** — dostupné zdroje nestačí k poctivému závěru.
- **V ROZPORU S DŮKAZY** — kvalitnější dostupné zdroje tvrzení přímo zpochybňují.

Ke statusu napište krátké **PROČ**.

## 5. Důkaz práce

Výstup má obsahovat:

1. původní tvrzení,
2. seznam zdrojů,
3. srovnávací tabulku,
4. finální status,
5. krátké vysvětlení rozhodnutí.

## 6. Reflexe

Každý účastník stručně odpoví:

- Co jsem si na začátku myslel/a?
- Co mě během ověřování překvapilo?
- Kterému zdroji jsem nejdřív věřil/a a proč?
- Co bych příště ověřoval/a jinak?

## Role učitele

Učitel nedává „správnou odpověď“. Pomáhá držet hranice zadání, ptá se na kvalitu důkazu a odděluje fakt od domněnky.

Užitečné otázky:

- „Jak to víme?“
- „Co by tento závěr vyvrátilo?“
- „Je zdroj skutečně relevantní k našemu tvrzení?“
- „Co stále nevíme?“

## Bezpečné hranice

- Nepoužívejte lekci pro diagnostiku lidí, zdravotní rozhodování nebo posuzování osobnosti.
- Citlivá osobní data nejsou pro aktivitu potřeba.
- AI může pomoci hledat otázky nebo strukturovat informace, ale nemá být vydávána za zdroj důkazu bez ověření.

## Co má vzniknout

Ne „správný člověk“ ani skóre. Výsledkem je **doložitelná zkušenost s ověřováním tvrzení** a reflexe toho, jak účastník pracoval s nejistotou.

---

Pansofie — pracovní ukázka pro první pilotní ověřování. Materiál se může měnit podle zpětné vazby z reálné výuky.
