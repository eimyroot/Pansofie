# PANSOFIE Master Boards V2

Status: CANDIDATE visual contract
Date: 2026-09-19
Depends on: `docs/architecture/MASTER_EXPERIENCE_V2.md`

## Purpose

This document defines three separate but related mockup boards that can be translated into production UI without baking screenshots into the product.

The boards are visual contracts for layout, typography, hierarchy, asset roles and responsive behavior.

---

# Board A — PANSOFIE

## Product role

Public editorial / knowledge / ecosystem web.

## Feeling

Calm, human, intelligent, grounded, civic, intergenerational, European editorial.

## Composition

The board should show seven implementation-ready frames:

```text
A1 Homepage
A2 7 growth paths
A3 16 development domains
A4 Domain detail
A5 Project detail
A6 Community / network
A7 Impact
```

## A1 Homepage

Hero direction:

```text
Eyebrow: PANSOFIE · MEZINÁRODNÍ EKOSYSTÉM PRO UČENÍ ŽIVOTEM
H1: Rozumět světu. Žít v něm vědoměji. Tvořit ho společně.
Lead: Pansofie propojuje poznání se skutečným životem, vztahy, přírodou, tvorbou a konkrétními činy.
Primary CTA: Objev Pansofii
Secondary CTA: Začni svou cestu
```

Section order:

```text
Hero
What Pansofie is
7 paths
16 domains
LEARN → PLAY → DO → CREATE → SHARE → REFLECT
Pansofie GO bridge
One real mission
Programs
Family Team + Knowledge Exchange
Community / places
Impact Index
Audience entry points
Final CTA
```

## A2 Seven paths

Source-derived target labels:

```text
Tělo
Mysl
Charakter
Vztahy
Tvořivost
Prosperita
Smysl
```

Each path card needs:

```text
path icon
number
name
one-line principle
short skill cluster
route handoff
```

Visual role: stronger than the 16-domain icon family. These are orientation / identity markers.

## A3 Sixteen domains

Cards should feel editorial, not like a gamified dashboard.

Each card contains:

```text
quiet domain icon
number
title
one-line learning focus
key skill
```

## A4 Domain detail

Required anatomy:

```text
Hero
Why it matters
What we learn
Key skill
Learn
Play
Do
Create
Share
Reflect
Missions
Projects
People / stories
Real-life connection
Impact
Next step into GO
```

## A5 Project detail

Required components:

```text
Project hero
Program owner
Place / context
Overview
People / organizations
Mission list
Timeline / updates
Evidence summary
Impact dimensions
Join / participate CTA
Truth label (real / pilot / demo / concept)
```

## A6 Community / network

Show:

```text
people
organizations
hubs
projects
map/network relationship
safe public profile previews
```

No decorative fake network visualization presented as live data.

## A7 Impact

Show the eight dimensions independently:

```text
Knowledge
Skills
Well-being
Family
Community
Nature
Entrepreneurship
Intergenerational Connection
```

Human rating and project impact must stay separate.

## Typography

Target pairing:

```text
Display serif: editorial, warm, high legibility
UI sans: neutral, modern, accessible
```

Avoid overusing all-caps. Small caps / tracked labels may be used for section eyebrows.

## Palette

Core direction:

```text
Warm cream
Warm white
Forest green
Sage
Charcoal
Restrained copper / terracotta
Muted gold only as a secondary accent
```

## Photography families

```text
hero / landscape / contemplation
family / intergenerational collaboration
school / hands-on learning
community projects / local action
nature / growing / food / materials
organizations / partnership / impact
```

All primary heroes should have composition-aware crops where needed:

```text
16:9 desktop
4:3 tablet
4:5 mobile
left-safe
right-safe
```

# Board B — PANSOFIE YOUNG

## Product role

Public youth experience and gateway into action.

Young is not the GO app.

## Feeling

Youth magazine + community board + discovery surface. Expressive but credible. Energetic without looking childish.

## Composition

The board should show:

```text
B1 Public Home
B2 Discover / 7 paths + 16 domains
B3 Story / quiz / dilemma
B4 Mission handoff
B5 Projects
B6 Community
B7 Younger presentation
B8 Older presentation
B9 Doodle / sticker / icon language
```

## B1 Public Home

Recommended hero language:

```text
H1: Objev svět. Zkus něco. Vytvoř něco, co má smysl.
Lead: Pansofie Young je prostor pro otázky, nápady, skutečné mise a projekty.
CTA 1: Objevuj
CTA 2: Zkus misi
```

Home sequence:

```text
Hero
What is happening now
7 paths
16 domains
Stories / questions
Mission gateway
Projects
Community
Family / team bridge
GO handoff
Safety promise
```

## B2 Discover

Do not reduce discovery to four generic themes.

Use:

```text
7 paths = strong orientation layer
16 domains = deeper topic/content layer
```

Filters can present both without flattening them into one taxonomy.

## B3 Story / quiz / dilemma

Young content interactions may use:

```text
short article
quiz
opinion scale
dilemma
mini-series
reflection prompt
```

These are discovery mechanics, not evidence/portfolio completion flows.

## B4 Mission handoff

Public Young can preview a mission:

```text
mission cover
program
path/domain tags
estimated effort
what you will actually do
skill outcome
CTA: Pokračovat v GO
```

Evidence and private reflection happen inside GO.

## B5 Projects

Project cards must map media by project meaning, never by array position.

Each card:

```text
image
program
project name
short purpose
place/context if public-safe
status
safe CTA
```

## B6 Community

Public community surfaces center on:

```text
themes
stories
teams/projects
moderated discussion previews
community guidelines
safe participation model
```

Do not expose child-to-unknown-adult direct messaging.

## B7 / B8 Age adaptation

Product target currently discussed as 6–18. Authentication split is currently different and must not be silently changed in a visual pass.

Younger presentation:

```text
larger tap targets
shorter text
strong illustration support
simple verbs
fewer simultaneous choices
guardian-context actions
```

Older presentation:

```text
more editorial density
real photography
stronger project/community framing
less decorative character art
more independent navigation
```

## B9 Young asset language

Use real photography plus separate overlay assets:

```text
photos
transparent doodles
stickers
icons
simple illustrations
```

Do not bake handwritten copy into hero photographs.

Accent palette may include:

```text
forest green
lime
cyan / turquoise
coral
warm yellow
select pink / violet accents
```

Keep enough shared green/cream DNA to remain recognizably Pansofie.

# Board C — PANSOFIE GO

## Product role

Shared action application for missions, projects, teams, map, evidence, reflection, portfolio and impact.

## Feeling

Mobile-first, fast, clear, motivating, structured.

## Composition

The board should show at least:

```text
C1 Home
C2 Mission list
C3 Mission detail
C4 Mission execution / evidence
C5 Reflection / completion
C6 Map / checkpoint
C7 Project
C8 Teams / Family Team
C9 Portfolio / skills
C10 AI mentor
C11 Profile / settings
C12 Empty / loading / error / locked states
```

## C1 Home

Home should answer:

```text
What am I doing now?
What is my next useful step?
What project/team/context am I in?
What changed since last time?
```

It must not become a wall of decorative statistics.

## C2 Mission list

Each mission card:

```text
cover
program
path/domain
effort
context requirement
status
one clear CTA
```

XP may be shown as game progress, never human worth.

## C3 Mission detail

Mission anatomy:

```text
title
purpose
real-world action
LEARN / PLAY / DO / CREATE / SHARE / REFLECT metadata
skills
safety / supervision requirements
steps
evidence expectation
context / people / place
start / continue CTA
```

## C4 Evidence

States:

```text
camera
upload
text / note
pending
verified / accepted where governed
private by default where appropriate
```

## C5 Reflection

Reflection is a private learning layer by default. It must not be turned into public performance.

## C6 Map

Pins are semantic:

```text
mission
project
event
lab
mentor
```

For minors, do not expose exact child-home location or unsafe proximity data.

## C7 Project

Show:

```text
goal
program
team
missions
updates
evidence
impact
place/context
participation state
```

## C8 Teams / Family Team

Family Team must preserve individual identity and permissions.

No shared family password / profile pretending all family members are one person.

## C9 Portfolio

Portfolio structure:

```text
experiences
skills
evidence
reflections
projects
selected public items
private items
```

Badges and XP supplement the portfolio; they do not replace it.

## C10 AI mentor

AI mentor flow:

```text
poznat → pochopit → vyzkoušet → vytvořit → reflektovat → pokračovat
```

UI must make clear that AI does not replace a guardian, teacher, professional or emergency support.

## C11 Profile / settings

Include:

```text
identity
active context
privacy
notifications
language
accessibility
guardian / organization relationships where relevant
AI settings
location permissions
community permissions
```

## C12 State system

Every core view needs deliberate states:

```text
loading
empty
error
offline where relevant
locked
permission denied
requires guardian approval
requires organization membership
completed
```

# Generation workflow

```text
page architecture
→ wireframe role
→ asset role
→ art-direction prompt
→ generate / source scene
→ curate one direction
→ crop / grade / normalize
→ vector cleanup where applicable
→ semantic registration in code
→ responsive integration
→ viewport screenshots
→ board comparison
→ accessibility / alt intent review
```

The final design package should be editable in a design tool and independently reconstructible from production components. A single beautiful board PNG is reference evidence, not the product source.
