# PANSOFIE SCHOOL PILOT KIT V1.0

Status: PROPOSED FOR PILOT / PRE-DEPLOYMENT
Date: 2026-08-17
Target: 2nd stage of Czech primary school (roughly ages 11–15)
Canonical parent: PANSOFIE MASTER ARCHITECTURE V1.0

## Purpose

This kit turns the canonical PANSOFIE Method into a school-run pilot that can be delivered with bounded teacher workload, explicit child-safety rules, curriculum mapping, evidence, reflection and measurable outcomes.

It is deliberately smaller than the full PANSOFIE vision.

## Pilot spine

`School onboarding → 3 Experiences → Evidence → Reflection → Teacher review → Passport → PANSOFIE DAY → Evidence Review`

The three pilot Experiences test three different value hypotheses:

1. `ZLEPŠI SVOU ŠKOLU` — learner agency and local participation.
2. `DIGITÁLNÍ MOST` — intergenerational cooperation and safe digital competence.
3. `CIRCULAR CHALLENGE` — school/company/community challenge, material/resource literacy and adoption/impact.

## Pilot non-goals

The pilot does not attempt to validate:
- a global marketplace;
- an open child network;
- AI evaluation of learners;
- automated career/personality assessment;
- a single human score;
- public child profiles;
- billing automation;
- broad international scale.

## Pre-deployment gate

Before this kit can be run through the live platform:
- target Supabase environment identity must be verified;
- backup/export evidence must exist;
- R0.1 → R0.2 → R0.3 migrations must be applied in order;
- learner/teacher/guardian/unauthorized RLS/RPC tests must pass;
- revision/resubmit lifecycle must pass;
- browser E2E golden path must pass;
- incident owner, data controller roles and school contact points must be assigned.

## RVP note

The crosswalk is a PANSOFIE interpretation of the currently available revised RVP ZV competency framework. It is not an official MŠMT certification and must be reconciled with each school’s current ŠVP before delivery.
