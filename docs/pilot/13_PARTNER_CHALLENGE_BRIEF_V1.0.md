# PANSOFIE — PARTNER CHALLENGE BRIEF V1.0

Status: PILOT INTAKE TEMPLATE
Audience: company / municipality / NGO / school problem owner

## Principle

PANSOFIE does not need a sponsor slogan. We need a real, bounded problem learners can investigate safely.

## Challenge intake

1. **Problem** — what is happening now?
2. **Why it matters** — who is affected and what resource/environment/community issue exists?
3. **Baseline** — what can be measured now? units/week, kg/month, process time, error count, unused items, participation count.
4. **Constraints** — budget, safety, law, operations, hygiene, brand-neutrality, time.
5. **Resources** — problem data, safe material sample, expert interview, facility visit, feedback, adoption opportunity.
6. **Material safety** — if materials are involved, provide provenance/composition and accept screening.
7. **Partner role** — Challenge / Material / Knowledge / Facility / Adoption / Funding Partner.
8. **Learner boundary acknowledgement** — no behavioural advertising, product placement requirement, child-data targeting, unrestricted private messaging or access to private reflection without separately justified purpose.
9. **Adoption path** — review / refinement / small pilot / partial / full adoption.
10. **Outcome metric** — if adopted, which metric and period could show change?

## Acceptance criteria

Challenge must be real, bounded, age-appropriate/safe, non-exploitative, measurable at least at output level, compatible with teacher workload, educationally meaningful and possible without unnecessary child data.
