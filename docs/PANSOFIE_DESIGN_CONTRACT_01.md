# PANSOFIE DESIGN CONTRACT 01

Status: **LOCKED / canonical visual authority**

Canonical source: **Mockup 01 — Pansofie, ekosystém pro učení životem**.

## Visual thesis
Pansofie is a living ecosystem / atlas of relationships. The public Adult website must not look like a generic NGO, eco project, school portal, SaaS dashboard or lifestyle magazine.

## Binding palette
- Deep green `#1B4D3A`
- Moss `#6B8B58`
- Sage `#A7B99A`
- Clay `#D7B899`
- Cream `#FAF7EF`
- Anthracite `#2F2F2F`

## Typography
Production target: editorial serif + neutral sans. Preferred pair: **Fraunces + Inter** with safe local serif/sans fallbacks when the canonical webfont is not bundled.

## Graphic language
Use relationship lines, nodes and circles, botanical linework, organic material shapes, maps/place layers, restrained editorial annotations and one consistent line-icon family. The system should feel like an atlas + cultural journal + living system, not app widgets.

## Photography
Photography is documentary evidence, not default decoration. Generic eco stock, staged corporate groups, anonymous plant-holding hands, unrelated scenery and "close enough" repository images are not acceptable production substitutes.

## 7 paths + 16 areas
These are primary identity assets and must recur as visual grammar across the public site, not only on dedicated pages.

## Page grammar
Home = ecosystem introduction. Objevuj = atlas/editorial exploration. Projects = real-world stories and systems. Community = people + places + organisations + knowledge exchange. Schools/Organisations = editorial institutional entry points. Articles/Library = magazine + knowledge atlas. Contact/Join = human and simple.

## Hard NO
No generic NGO visual style, generic eco stock, generic SaaS cards, dashboard leakage, random illustration styles, legacy fallback, arbitrary colours or page-specific visual languages.

## Fidelity gate
A public Adult page does not ship merely because it builds. Before release it must pass: brand atmosphere, typography, palette, composition, imagery/art direction, ecosystem graphic language, spacing, responsive character and no legacy fallback.

When implementation and Mockup 01 disagree, Mockup 01 wins unless accessibility or function requires adaptation. The adaptation must preserve the same visual character.
