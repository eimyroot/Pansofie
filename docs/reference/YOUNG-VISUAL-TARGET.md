# Young visual target mapping

The supplied visual references are the canonical target for composition and tone.

## `/young/kids`

Target characteristics:

- bright illustrated world
- playful handwritten accents
- large visual hero
- green primary actions
- four topic cards
- four activity cards
- three weekly article cards
- community banner
- mobile-first responsive collapse

## `/young/teens`

Target characteristics:

- editorial/photo-led visual language
- high-contrast typography
- fluorescent/lime annotation accents
- four topical cards
- three editorial article cards
- four action formats
- dark-green community banner
- distinct navigation from Kids
