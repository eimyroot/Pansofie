# Young asset gap

The supplied visual reference pack specifies final individual assets for Kids and Teens heroes (desktop/tablet/mobile), topics, articles, banners, avatars and shared icons.

Those exact `young-kids/...` and `young-teens/...` WebP binaries are not currently tracked in the GitHub repository. The current implementation therefore uses only existing repository-owned artwork under `/art/pansofie-v1` and `/assets` as safe fallbacks.

No external image hotlinks or untracked binary dependencies were introduced. When the final individual asset files are committed, image-path arrays can be switched to the canonical files without changing routing, authorization, shells or page architecture.
