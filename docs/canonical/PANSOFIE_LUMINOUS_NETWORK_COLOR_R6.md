# PANSOFIE Luminous Network / Color R6

## Purpose

R6 adds a semantic light/color language on top of the verified R5 living network. The goal is more energy and visual memorability without turning the public product into a neon dashboard.

## Contract

- PANSOFIE green remains the stable core / trust color.
- Color blooms when a node or relationship becomes active; quiet state remains restrained.
- Role colors are orientation cues, never human scores or classifications.
- Process colors express function (need, action, evidence, reflection, verification, decision, outcome, boundary), not value judgements.
- Active network links carry a visible colored travelling signal.
- The route ribbon, network ambient field, selected node and detail cards share one active semantic accent.
- Homepage network performs a short calm awakening: core -> links -> nodes -> details.
- `prefers-reduced-motion: reduce` removes decorative/awakening animation while preserving information and interaction.
- Mobile remains bounded and readable; luminance is reduced relative to desktop.

## Palette grammar

- Core / trust: deep PANSOFIE green
- Learner / verification: jade
- Family / need: warm amber
- School / pilot: teal
- Mentor / reflection / review: violet
- Partner / action / challenge: coral
- Community / outcome / impact: olive-lime
- Evidence / output: cyan
- Passport / decision / transfer: blue
- Safety / boundaries / privacy: deep teal-green

## Whole-site application

The shared public network shell carries the active semantic accent through:

1. route ribbon active node and completed connections,
2. ambient pointer field and light sweep,
3. active public-nav state,
4. active section edge light,
5. shared R5 reference network,
6. node active/related states,
7. core halo,
8. active SVG links and travelling signal,
9. identity / receives / contributes / boundary cards,
10. active flow strip.

## Truth boundaries

Unchanged from R5:

- Experience remains central.
- Activity != Output != Adoption != Outcome != Impact.
- No human-worth score or child profiling.
- No unrestricted adult-child private messaging.
- Partner reviews output against the brief, never human value.
- Passport remains private-by-default.
- Technical readiness is not proof of field/pedagogical impact.
- No claim that a real field pilot has run.
