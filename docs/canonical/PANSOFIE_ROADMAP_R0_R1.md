# PANSOFIE ROADMAP — R0 → R1

Status: CANONICAL EXECUTION ROADMAP

## R0 — Canonical Foundation
Goal: one source of truth; stop architecture drift.

Deliverables:
- Product Constitution V1.0
- Master Architecture V1.0
- 7 Paths dictionary
- PANSOFIE Method
- Experience Standard
- Child Promise / safeguarding baseline
- Research Baseline
- Project Skillset
- CASER Source of Truth registration

Exit gate: all public/product work references this baseline.

## R0.1 — Repository Alignment
Goal: reconcile current React/Supabase product with canonical architecture.

Tasks:
- audit current routes/components/data models;
- map prototype content to Programs/Labs/Experience entities;
- identify legacy concepts that conflict with V1.0;
- define migration without deleting evidence;
- add branch protection / CI observability where possible;
- establish architecture and data-contract tests.

Exit gate: repo reflects canonical terminology without breaking auth/current product.

## R0.2 — School Pilot Kit
Goal: make pilot possible before expanding the platform.

Deliverables:
- teacher playbook;
- 3 pilot Experiences;
- RVP mapping;
- reflection rubric;
- evidence rules;
- safeguarding/consent pack;
- teacher-load budget;
- parent information sheet;
- PANSOFIE DAY toolkit;
- pilot measurement plan.

Exit gate: a school can run the program without bespoke founder intervention every session.

## R0.3 — Minimal Digital Pilot Support
Minimum functionality:
- secure identity;
- mission/Experience assignment;
- evidence capture;
- reflection;
- Passport entry;
- teacher review;
- basic impact export;
- no open social feed.

Exit gate: end-to-end Experience flow works for pilot users.

## R0.4 — Pilot
Target:
- 2–3 schools;
- 60–120 learners;
- ~8 weeks;
- 3 Experiences;
- final PANSOFIE DAY.

Measure:
- activation;
- completion;
- second-Experience rate;
- evidence completion;
- reflection completion;
- teacher prep/review time;
- learner qualitative value;
- parent value;
- school renewal intent;
- willingness to pay;
- safeguarding incidents/near misses;
- technical failure rate.

## R0.5 — Evidence Review
Decision: VALIDATE / CHANGE / STOP.

No vanity success criteria.

## R1 — Productization
Only after pilot evidence:
- finalized School licence package;
- pricing;
- onboarding;
- teacher training;
- richer Mission Library;
- Passport UX;
- impact reporting;
- governed AI assistance;
- first repeatable sales process;
- selected partner/foundation/grant applications supported by evidence.

## Deferred beyond R1
- World League;
- open child network;
- marketplace;
- large physical campus;
- broad internationalization;
- advanced recommendation graph until enough evidence/data exists.
