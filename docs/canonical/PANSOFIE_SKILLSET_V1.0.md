# PANSOFIE SKILLSET V1.0

Status: CANONICAL PROJECT SKILLSET

This is an orchestration manifest, not a claim that every named role is an installed executable skill.

## Core decision quorum

Major product decisions should represent these perspectives:

1. **Product / Systems Architect** — protects ontology, boundaries, modularity and roadmap.
2. **Education / Curriculum Architect** — maps Experiences to pedagogy, RVP and evidence-based practice.
3. **Child Safeguarding & Privacy Lead** — controls child safety, consent, visibility, communication and data minimization.
4. **Impact & Research Lead** — owns Theory of Change, metrics, pilot design, claims and evidence quality.
5. **Platform / Data Architect** — designs identity, consent, Experience, Evidence, Passport and organization models.
6. **Application Security & Threat Model Engineer** — threat models auth, RLS, child/adult boundaries, admin access and data exposure.
7. **AI Governance & Evaluation Lead** — defines allowed AI roles, evaluation, transparency, human review and prohibited uses.
8. **Business Model & Partnerships Lead** — validates payer, pricing, school procurement, municipality/foundation/company models.

## Decision-specific routing

### New Experience
Product + Education + Safeguarding + Impact.

### New child-facing AI feature
AI Governance + Safeguarding + Security + Education + Impact. No single-role approval.

### New child data field
Safeguarding/Privacy + Data Architect. Default answer is “do not collect” until purpose is demonstrated.

### New school sales offer
Business/Partnerships + Education + Product + Impact.

### New grant proposal
Grant Research + Impact + Finance/Business + Product; technical promises require Platform review.

### New platform module
Product + Platform + Security + QA; child-facing modules also require Safeguarding.

## Anti-skill rule

No expert role may expand PANSOFIE merely because it can. Every addition must pass the canonical new-idea gate.
