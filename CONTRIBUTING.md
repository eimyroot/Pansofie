# Contributing

Thanks for contributing to Pansofie.

## Before you start

- Open an issue for substantial product, data-model, privacy, youth-safety, or architecture changes.
- Keep changes narrowly scoped and avoid unrelated refactors.
- Never commit credentials, secrets, production data, student data, family data, or other personal information.
- Changes affecting youth experiences must preserve age-appropriate UX, privacy, consent, and safeguarding boundaries.

## Development

Use the environment and commands documented in the repository. Install dependencies from the lockfile, run the available checks, and verify affected flows locally before opening a pull request.

## Pull requests

Explain what changed, why it changed, how it was tested, and any accessibility, privacy, youth-safety, compatibility, or security impact. Keep generated files and unrelated formatting churn out of the diff.

By contributing, you agree that your contribution is submitted under the repository's existing license and project terms unless a separate written agreement applies.
